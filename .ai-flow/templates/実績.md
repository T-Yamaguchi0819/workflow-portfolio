## 指標の定義

| キー | 意味 |
|------|------|
| human_hours_actual | AI利用時に人間が実際に使った時間（指示・確認・レビュー含む） |
| human_hours_baseline | AIを使わなかった場合の想定時間（担当者見積もり）。削減率はこの2つから算出される |
| ai_hours | AI実行時間（参考値） |
| first_pass | 最初の[6]動作確認で全観点PASSしたか |
| rework_count | Plan/テスト/実装への差し戻し回数（レビュー往復含む） |
| ai_findings_effective | [5]レビューの指摘のうち実際に修正につながった数 |
| human_findings | **AIレビュー後に人間が発見した問題数**（重要指標。PR の人間レビュー指摘を含む。内容は下に記載） |
| escalations | 🛑 エスカレーション（レビュー2往復超・テスト3回失敗等）の発生回数 |
| flow_completed | フローを完遂したか。途中で従来手順に切り替えた場合は false＋理由を特記事項へ |
