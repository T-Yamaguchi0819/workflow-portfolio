## AI修正フロー（ai-dev-flow）

本プロジェクトには `.ai-flow/` の修正フローが導入されている。

- **修正タスクは `.ai-flow/FLOW.md` の統括手順に従って進める**（フェーズ 0〜8・S/M/L 分岐・ゲート定義はそこが正）。作業状態は `.ai-flow/work/{タスク名}/_state.md` に常に保存し、セッションをまたいで再開できるようにする
- プロジェクト固有の値（技術スタック・ビルド/テストコマンド・禁止事項・リスク分類・コミット規約）は **`.ai-flow/project.yaml` が正**。コード修正の前に必ず読む
- 単発の小修正でも `project.yaml` の `constraints` と `git`（ブランチプレフィックス・コミット書式）は遵守する
- ユーザーへ確認する前に `.ai-flow/knowledge/defaults.md`・`precedents.md` を引く（記載済み項目は確認不要。適用したことを報告する）
- **[5]独立レビューをこのセッションで実装に続けて行わない**。レビューは新しいセッションで `.ai-flow/flow/5-review.md` に従って実行する（レビュー時は `impl.md` と実装経緯を読まない）
- **コミット/push の可否は `.ai-flow/project.yaml` の `git.commit_policy` に従う**（`manual`: ユーザー明示指示時のみ／`auto`: フェーズ完了ごとに自動コミット・push、最終承認は PR マージ。マージは人間が行う）。コミットは pre-commit フックの禁止パターンLintでブロックされることがある。ブロックされたら違反を解消する（誤検知と思っても独断で `--no-verify` 等で回避しない）
