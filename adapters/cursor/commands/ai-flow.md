# /ai-flow — AI修正フロー統括（Cursor）

まず `.ai-flow/FLOW.md` と `.ai-flow/project.yaml` を読み、FLOW.md の統括手順に厳密に従って修正フローを実行せよ。対象タスクはユーザーの直前の指示（またはこのコマンドへの引数）から特定する。

Cursor 固有の実行方法:

1. **状態の確認**: `{work_dir}/{タスク名}/_state.md` を読む。無ければフェーズ0から、あれば進捗マトリクスの未完了の最初のフェーズから再開する
2. **フェーズは同一チャット内で順次実行**する。各フェーズ開始時に該当する `.ai-flow/flow/{N}-*.md` を読み、その手順・成果物・完了条件に厳密に従う。フェーズ完了ごとに `_state.md` を更新する
3. **ゲートで停止**: FLOW.md のゲート定義（AC承認・Plan承認・レビュー後・ドキュメント前・完了時）では必ずユーザーに結果を提示し、承認を得てから次へ進む。確認事項はゲートまで貯めて一括で聞く
4. **[5]独立レビューはこのチャットで行わない**。[4][6] が終わったら、ユーザーに「新しいチャットで `/ai-flow-review` を実行してください（対象タスク・Noを添えて）」と依頼して停止する。`review.md` が書かれた後に再開する
5. **コミット/push の可否は `.ai-flow/project.yaml` の `git.commit_policy` に従う**（`manual`: ユーザー明示指示時のみ／`auto`: フェーズ完了ごとに自動コミット・push）
