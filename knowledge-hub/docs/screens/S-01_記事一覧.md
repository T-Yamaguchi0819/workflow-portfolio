# 画面設計書 S-01 記事一覧・検索

| 項目 | 内容 |
|------|------|
| 画面ID / 画面名 | S-01 / 記事一覧・検索 |
| パス | `/articles`(`/` からもリダイレクト) |
| レンダリング | SSR(Server Component・動的) |
| 実装 | `frontend/src/app/articles/page.tsx` |
| 使用API | A-01 `GET /api/articles?category=&tag=&q=` |

## 1. 画面概要

登録済みナレッジ記事を更新日時降順で一覧表示し、キーワード・カテゴリ・タグで絞り込む。検索条件は URL クエリに保持する(ブックマーク・共有可能。画面側に状態を持たない)。

## 2. 画面レイアウト

```
+--------------------------------------------------------------+
| [知] Knowledge Hub                     記事一覧  [＋記事を書く] |  ← 共通ヘッダー
+--------------------------------------------------------------+
| ARTICLES ／ 記事一覧                                    N 件   |
| ナレッジを探す                                                 |
+--------------------------------------------------------------+
| ▌検索パネル                                                   |
| [ キーワードで検索 (タイトル・本文)         ] [検索]           |
| CATEGORY (すべて) (IT-FAQ) (総務) (開発) …    ← 動的生成      |
| TAG (#VPN) (#経費) …                          ← 動的生成      |
+--------------------------------------------------------------+
| +----------------------------------------------------------+ |
| | [カテゴリ] 更新 yyyy/mm/dd                                | |
| | 記事タイトル(明朝・ホバーで朱色)                          | |
| | 本文抜粋(最大2行、Markdown記法除去)…                      | |
| | #タグ1 #タグ2                                             | |
| +----------------------------------------------------------+ |
| (記事カード × N。0件時は空状態表示)                           |
+--------------------------------------------------------------+
```

## 3. 画面項目定義

| # | 項目 | 種別 | 出所・仕様 |
|---|------|------|-----------|
| 1 | 件数 | 表示 | 検索結果の件数。強調数字+「件」 |
| 2 | キーワード入力 | input(search) | 初期値 = クエリ `q`。placeholder「キーワードで検索 (タイトル・本文)」 |
| 3 | 検索ボタン | button(submit) | GET サブミット(§4-1) |
| 4 | カテゴリチップ | リンク群 | 全記事から distinct 抽出・昇順。「すべて」+ 各カテゴリ。選択中は反転表示(`chip--active`) |
| 5 | タグチップ | リンク群 | 全記事のタグを distinct 抽出・昇順。破線枠(`chip--tag`)。選択中は反転表示 |
| 6 | 記事カード | リンク | クリックで S-02 へ。カテゴリバッジ / 更新日(`ja-JP` yyyy/mm/dd) / タイトル / 抜粋 / タグピル |
| 7 | 抜粋 | 表示 | 本文から Markdown 記法(見出し・強調・リスト記号等)を除去し先頭 120 文字。CSS で 2 行に丸め |
| 8 | 空状態 | 表示 | 「条件に一致する記事がありません。」+ 案内文(0 件時のみ) |

### 補足仕様

- チップの候補(項目 4・5)は**絞り込み前の全件**から生成する(絞り込み結果だけから作ると他の選択肢が消えるため)。絞り込み中のみ全件取得を追加実行
- 記事カードの並び順は API 側で `updatedAt` 降順ソート済み

## 4. イベント定義

| # | トリガー | 処理 | 遷移先 |
|---|----------|------|--------|
| 4-1 | 検索ボタン / Enter | GET フォーム送信。現在の `category`・`tag` は hidden で維持 | `/articles?q={入力値}&…`(本画面) |
| 4-2 | カテゴリチップ | 選択トグル(選択中のものを押すと解除)。他条件はマージ維持 | `/articles?category=…`(本画面) |
| 4-3 | タグチップ | 同上 | `/articles?tag=…`(本画面) |
| 4-4 | 記事カード | — | S-02 `/articles/{id}` |
| 4-5 | ＋記事を書く(ヘッダー) | — | S-03 `/articles/new` |

絞り込み 3 条件は AND。`category` は API 側で GSI Query、`tag`・`q` はサービス層フィルタ(詳細は全体設計書 §4.2)。

## 5. 異常系・特殊状態

| 状態 | 挙動 |
|------|------|
| 検索結果 0 件 | 空状態表示(項目 8)。検索パネルは操作可能なまま |
| API 接続不可 | Next.js のエラーバウンダリ(既定のエラー画面)。※本画面専用のエラー UI は現スコープ外 |
