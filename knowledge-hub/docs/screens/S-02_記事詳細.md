# 画面設計書 S-02 記事詳細

| 項目 | 内容 |
|------|------|
| 画面ID / 画面名 | S-02 / 記事詳細 |
| パス | `/articles/{id}` |
| レンダリング | SSR(Server Component・動的)。削除ボタンのみクライアント(`DeleteButton`) |
| 実装 | `frontend/src/app/articles/[id]/page.tsx`(404: 同 `not-found.tsx`) |
| 使用API | A-02 `GET /api/articles/{id}` / A-05 `DELETE /api/articles/{id}`(削除時) |

## 1. 画面概要

記事 1 件の本文を Markdown レンダリングで表示する。編集・削除への入口を持つ。

## 2. 画面レイアウト

```
+--------------------------------------------------------------+
| ← 記事一覧に戻る                                              |
+--------------------------------------------------------------+
| [カテゴリ] #タグ1 #タグ2            ← タグはリンク            |
| 記事タイトル(明朝・下線 = 墨 + 朱のアクセント)                |
| ------------------------------------------------------------ |
| 本文(Markdown レンダリング)                                   |
|   ▌見出し(朱の左ボーダー) / 箇条書き / 表 / コード等          |
| ------------------------------------------------------------ |
| 作成: yyyy/mm/dd hh:mm  最終更新: yyyy/mm/dd hh:mm  ID: …     |
| ------------------------------------------------------------ |
| [編集する] [削除する]                                         |
+--------------------------------------------------------------+
```

## 3. 画面項目定義

| # | 項目 | 種別 | 出所・仕様 |
|---|------|------|-----------|
| 1 | 戻るリンク | リンク | 「← 記事一覧に戻る」 |
| 2 | カテゴリバッジ | 表示 | `category`。朱枠バッジ |
| 3 | タグ | リンク群 | 各タグ。クリックで当該タグ絞り込みの一覧へ |
| 4 | タイトル | 表示 | `title`。ページタイトル(`<title>`)にも設定 |
| 5 | 本文 | 表示 | `body` を react-markdown + remark-gfm でレンダリング(表・タスクリスト等 GFM 対応)。**生 HTML は挿入しない**(XSS 回避) |
| 6 | 作成/更新日時 | 表示 | `createdAt` / `updatedAt` を `ja-JP` の年月日時分で表示 |
| 7 | 記事ID | 表示 | `id`(UUID)。問い合わせ・API 検証用 |
| 8 | 編集ボタン | リンク | S-04 へ |
| 9 | 削除ボタン | button(submit) | confirm 付き(§4-3) |

## 4. イベント定義

| # | トリガー | 処理 | 遷移先 |
|---|----------|------|--------|
| 4-1 | 戻るリンク | — | S-01 `/articles` |
| 4-2 | タグリンク | — | S-01 `/articles?tag={タグ}` |
| 4-3 | 削除ボタン | `window.confirm`「この記事を削除します。よろしいですか?」→ OK で Server Action → A-05 実行 → 一覧を revalidate | OK: S-01 `/articles` ／ キャンセル: 遷移なし |
| 4-4 | 編集ボタン | — | S-04 `/articles/{id}/edit` |

## 5. 異常系・特殊状態

| 状態 | 挙動 |
|------|------|
| 記事が存在しない(API 404) | `notFound()` により 404 専用画面へ。「お探しの記事は見つかりませんでした」+ 一覧へ戻るボタン |
| 削除時に記事が既に無い(API 404) | Server Action が例外 → Next.js エラーバウンダリ。※楽観的に許容(競合削除は稀) |
| API 接続不可 | Next.js のエラーバウンダリ(既定のエラー画面) |
