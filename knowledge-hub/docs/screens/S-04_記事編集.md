# 画面設計書 S-04 記事編集

| 項目 | 内容 |
|------|------|
| 画面ID / 画面名 | S-04 / 記事編集 |
| パス | `/articles/{id}/edit` |
| レンダリング | SSR + クライアントフォーム(`ArticleForm`、S-03 と共通コンポーネント) |
| 実装 | `frontend/src/app/articles/[id]/edit/page.tsx` / `frontend/src/components/ArticleForm.tsx` / `frontend/src/lib/actions.ts` |
| 使用API | A-02 `GET /api/articles/{id}`(初期表示) / A-04 `PUT /api/articles/{id}`(更新) |

## 1. 画面概要

既存記事を編集する。フォームの構成・入力項目・バリデーション・エラー表示は **S-03 記事作成と同一**(共通コンポーネント `ArticleForm` を使用)。本書では S-03 との差分のみ定義する。

## 2. S-03 との差分

| 観点 | S-03 記事作成 | S-04 記事編集(本画面) |
|------|---------------|------------------------|
| 見出し | NEW ／ 新規作成「記事を書く」 | EDIT ／ 編集「記事を編集する」 |
| 初期値 | 全項目空 | A-02 で取得した既存値。タグは `", "` 連結でテキスト化 |
| 戻るリンク | ← 記事一覧に戻る → S-01 | ← 記事に戻る → S-02 `/articles/{id}` |
| 送信ボタン | 作成する | 更新する |
| 送信処理 | A-03 POST(新規採番) | A-04 PUT(全項目置換。`createdAt` は保持、`updatedAt` はサーバーで更新) |
| 成功時遷移 | S-02(新規 id) | S-02(同一 id)。一覧と当該詳細を revalidate |
| キャンセル遷移 | S-01 | S-02 `/articles/{id}` |

入力項目定義・メッセージ一覧は [S-03](S-03_記事作成.md) の §3・§5 を参照。

## 3. 異常系・特殊状態

| 状態 | 挙動 |
|------|------|
| 記事が存在しない(初期表示時の API 404) | `notFound()` により 404 専用画面へ |
| 更新時 400(バリデーション) | S-03 §4-2 と同一(同一画面にエラー表示・入力値保持) |
| 更新対象が編集中に削除された(PUT が 404) | FormState にエラーメッセージ表示(「記事が見つかりません: {id}」)。遷移なし |
| API 接続不可 | S-03 §4-2 と同一 |
